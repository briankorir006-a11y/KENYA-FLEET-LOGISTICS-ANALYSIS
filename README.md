# KENYA-FLEET-LOGISTICS-ANALYSIS

\*\*Tool:\*\* Microsoft Excel  

\*\*Domain:\*\* Fleet Management, Procurement \& Logistics  

\*\*Period:\*\* January 2024 – December 2025  

\*\*Records:\*\* 1,380+ entries across 5 datasets  



\---



\## Project Overview

End-to-end data analysis of fleet operations, machinery 

utilization, purchase orders and delivery logistics across 

Kenya — covering counties from Nairobi to Garissa.



\---



\## Key Business Questions Answered

\- Which counties have the highest fleet operating costs?

\- What is machinery utilization across construction sites?

\- Which suppliers have the most delayed deliveries?

\- What is the on-time delivery rate by route?

\- What is the monthly trend in purchase order values?
